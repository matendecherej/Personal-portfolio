# Jewel Matendechere — Developer Portfolio

## Run locally
Extract this ZIP, then open index.html in your browser. Alternatively open the folder in VS Code and use Live Server. No npm install or build step is needed.

## Files
- index.html: complete page, CSS inside <style>, and JavaScript inside <script>.
- project-1.webp and project-2.webp: supplied project images.
- fonts/: self-hosted font files and their license.

## Personalise
- Photo: replace the .portrait-placeholder block with an <img> using your photo path. Give it descriptive alt text and style it with width:100%; aspect-ratio:4/5; object-fit:cover.
- Completion percentages: search for `const projectCompletion = [null, null, null, null]`. Replace null with your confirmed numbers from 0 to 100, in this order: SomaSide, YS Market, Blissful Glow Services, Twakula. Unknown percentages stay null.
- Contacts: search for `contact-directory`. Replace each pending contact div with an anchor to your profile, mailto: email, or tel: phone number. Remove its Coming soon label once supplied.
- Styling: the last CSS rules in <style> contain the dark layout and updated font pairing; later CSS overrides earlier rules.

## Deploy
Upload the contents to any static host, keeping the fonts folder and image paths intact. The site is static; there is no backend or contact form.
